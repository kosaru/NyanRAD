# NyanRAD

NyanQLフレームワーク群を、VB6のような統合開発環境で使えるようにする構想です。
VB6のように部品を配置して画面を作り、生成物をソースコードとして扱うことを目指します。

現在は人間の明示承認を受け、要件定義に着手しています。企画確認書は初稿です。正式Baseline・実装開始は未成立です。
