# NyanRAD

NyanQLフレームワーク群を使う、ブラウザ型ビジュアル開発環境の構想です。
VB6のように部品を配置して画面を作り、生成物をソースコードとして扱うことを目指します。

現在は初期構想の整理段階です。実装済み製品、承認済み要件、正式BaselineまたはCodexへの作業指示ではありません。
