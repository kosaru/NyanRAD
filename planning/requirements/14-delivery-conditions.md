# NyanRAD 初回提供条件の確認表

## 確認済み

初回はmacOSローカル利用。生成物はNyanQL群の通常ソース。実行ファイルは要求者側で用意し、リモートサービスはNyanQL群側で扱う。
専用管理サービスの追加は未採用。既存機能で保存・起動・停止の成立を調べる。

## 残る条件と影響

| 条件 | 現在の状態 | 決めないと固定できないこと |
|---|---|---|
| CPU | Apple Silicon／Intelの範囲は未決定 | 実行ファイルの種類、検証環境、提供範囲 |
| macOS | 最低対応版は未決定 | 対応保証とOS別の実行管理検証 |
| ブラウザ | 対象と版は未決定 | デザイナー操作・コード編集・プレビューの検証範囲 |
| 実行ファイル | 提供の前提は確認済み、具体的な版は未受領 | 現行ソースとの機能差、起動引数、実行環境の固定 |
| 内蔵DB | SQLite・DuckDBを検討、既定値と初回対応範囲は未決定 | 新規プロジェクトの設定とDB検証条件 |
| ライセンス | 未決定 | NyanRADと依存物の配布条件 |
| 期限・予算 | 未設定 | 工程計画と投入範囲。AIから値を補完しない |
| 受入条件 | 観点は整理済み、最終条件は未確定 | 初期版を完成と判断する条件 |
| 正式要件の保管 | 初回の単一リポジトリ方針のみ確認済み | 要件候補・正式要件・実装ブランチの対応 |

## 次に確認する順序

まず使用するMacのCPU・macOSと、普段使うブラウザを確認し、初回検証環境の候補を特定する。
その環境をそのまま最低対応要件とする判断は別に行う。
次に提供される実行ファイルの版と対応環境を照合する。
DBは初期設定と必要な確認例を比較し、人間が初回範囲を選ぶ。

## 既存の未決定動作

部分保存後の実行条件、競合画面の具体的な選択、強制停止の提供条件等は11-open-decisions.mdで継続。
編集操作の了承を、提供条件や未受領の実行ファイルの互換性保証へ読み替えない。
