# NyanRAD UI・機能・データの接続と整合確認（初稿）

UI・機能・データの初稿をつなぐ検討用の図。正式なIFDAM Package・Schema検証済み成果物ではない。
Rは参照、Cは作成、Uは更新、Dは削除。データは物理DBテーブルに限定しない。

## プロジェクトの作成・再開・保存

```mermaid
flowchart TD
 UI["プロジェクト操作画面"] -->|"新規・開く"| F["作成・読込"]
 F -->|"C/R"| P[("プロジェクト・ソース・設定")]
 F -->|"C"| E[("編集状態")]
 F --> V["一覧・編集可能範囲またはエラーを表示"]
 V -->|"保存"| S["保存先の変化と編集内容を確認"]
 E -->|"R"| S
 P -->|"R"| S
 S --> B{"競合があるか"}
 B -->|"なし"| W["変更を保存"]
 W -->|"U"| P
 W --> OK["対象別の保存結果"]
 B -->|"あり"| C["差分を表示して判断へ"]
 W -->|"失敗・部分保存"| ERR["未保存内容と失敗対象を表示"]
```

部分保存後の実行条件、競合解消の選択肢、未保存で切替・再読込する動作は未決定。

## フォーム・イベントの編集

```mermaid
flowchart TD
 UI["デザイン・プロパティ・コード画面"] -->|"配置・変更・コピー・整列"| F["フォームと部品を編集"]
 D[("フォーム・部品・プロパティ")] -->|"R"| F
 F -->|"C/U"| E[("編集状態・履歴")]
 F --> V["フォームの変更と未保存表示"]
 UI -->|"イベント選択"| H["既存処理を開く・未作成なら雛形を作る案"]
 L[("イベント対応・処理ソース")] -->|"R"| H
 H -->|"必要時C"| E
 H --> CODE["対象・実行場所を示すコード画面"]
 UI -->|"名前変更・削除"| X["参照と手書き処理への影響を確認"]
 L -->|"R"| X
 X --> ASK["影響を表示して判断へ"]
```

Undo／Redoは編集状態・履歴を参照更新し結果を表示する。保存は前図へつながる。
削除時のDと参照のUは対象範囲を決めてから定義する。手書き本文の連鎖削除を確定しない。

## サーバー処理・SQL・接続の編集

```mermaid
flowchart TD
 UI["製品別の処理・SQL・設定画面"] -->|"対象選択"| R["ソースと設定を取得"]
 D[("処理・SQL・API・DB設定")] -->|"R"| R
 R --> V["製品・実行場所・対象を表示"]
 V -->|"編集"| F["本文・設定の編集内容を反映"]
 F -->|"C/U"| E[("編集状態")]
 F --> OUT["変更または問題を表示"]
```

直接接続／Nyan8経由を扱う。生成アプリのDB処理とIDE管理データを区別する。
検査範囲、自動結線、認証情報の入力・持出しは未決定。

## 実行・確認・停止

```mermaid
flowchart TD
 UI["実行操作画面"] -->|"実行"| F["保存状態と対象を確認"]
 S[("保存結果・ソース・実行設定")] -->|"R"| F
 F --> B{"実行条件を満たすか"}
 B -->|"はい"| START["対象を起動"]
 START -->|"C/U"| RUN[("実行状態")]
 START --> OK["プレビュー・状態表示"]
 B -->|"未保存・部分保存等"| WAIT["理由と選択肢を表示：具体動作は未決定"]
 START -->|"失敗・競合"| ERR["対象と起動エラー"]
 OK -->|"ログ確認"| LOG["対象ログを取得"]
 RUN -->|"R"| LOG
 LD[("ログ・エラー")] -->|"R"| LOG
 LOG --> RES["修正の手掛かりを表示"]
 OK -->|"停止"| STOP["管理する対象へ停止要求・確認"]
 RUN -->|"R/U"| STOP
 STOP --> END["停止・失敗・不明を区別して表示"]
```

通常ソースの持出しは保存済みソース・設定を参照し、出力結果を返す。出力形式・実行ファイル同梱は未決定。
所有追跡、再接続、強制停止も未決定。状態不明を停止済みへ変換しない案。

macOS対応版・CPU・ブラウザ、配布バイナリ版、DB対応範囲、実行管理の技術成立、期限・予算・ライセンス・受入条件も未確定。
